# Fenpo for iPhone

Swift 6, SwiftUI, iOS 18+. The Xcode project is generated by XcodeGen and never committed.

## Build on a Mac

```bash
brew install xcodegen protobuf
ios/scripts/generate-proto.sh
cd ios && xcodegen generate && open Fenpo.xcodeproj
```

Signing uses the Milvasoft team (`Config/Base.xcconfig`). Run `generate-proto.sh` again whenever `protocol/` changes.

## Layout

| Path | Contents |
|---|---|
| `project.yml` | Targets: `Fenpo` (app), `FenpoShare` (share extension), `FenpoWidgets` (widgets) |
| `FenpoKit/` | Swift package. `FenpoProtocol` (generated types) and `FenpoCore` have no Apple framework dependencies; `FenpoApple` holds CoreBluetooth, Network.framework, CryptoKit and SwiftUI code |
| `Shared/Colors.xcassets` | Theme colors (Any/Dark), used by every target |
| `scripts/` | Protocol code generation, CI helpers |

## FenpoKit core on Windows

Install the Swift toolchain and protoc, then from Git Bash:

```bash
ios/scripts/generate-proto.sh
swift test --package-path ios/FenpoKit
```
